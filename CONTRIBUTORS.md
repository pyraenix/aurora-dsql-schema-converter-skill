# Contributors

Thank you to everyone who has contributed to the DSQL Schema Converter Skill.

## Maintainers

- **Prema Iyer** ([@pyraenix](https://github.com/pyraenix)) — Creator and lead maintainer

## How to Contribute

1. Fork this repo
2. Create a feature branch
3. Make your changes (edit files in `.kiro/skills/dsql-schema-converter/`)
4. Test by installing the skill in a Kiro project and running conversion prompts
5. Submit a PR with before/after examples

See [README.md](README.md) for full contributing guidelines.
